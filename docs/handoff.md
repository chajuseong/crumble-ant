## 1. 완료 보고서 (PR 본문 — `.github/pull_request_template.md`)
- 빌드 · 커밋 → 완료 조건별 결과와 **확인 방법** → 자동 확인 → 문서와 다르게 한 점 → Unity 이식 원칙 확인 → 질문 (추천 붙임) → 알려진 문제
- "확인했습니다"만 있는 보고는 받지 않는다 — **같은 순서로 따라 해서 같은 결과**가 나와야 한다

## 2. 검수 순서 (DD)
1. 변경 파일 (`node_modules` · `dist` · `logs` · `ci-smoke` 있으면 머지 안 함) · CI
2. 지시 · 정본 문서 (`docs/dev.md` · 기획서) 와 맞는지 · 예전 결정과 부딪히지 않는지
3. 화면이 바뀌면 스크린샷 (실제 플레이 순서 · 360 / 390 / 430 폭)
4. Unity 이식 원칙 7줄
5. 통과 → 머지 → `merged: true` · 해시 확인 → 결정 기록
