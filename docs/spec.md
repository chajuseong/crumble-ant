> 팔 4개, 다리 2개를 가진 개미가 하늘에서 떨어지는 건물을 점프해서 부수는 방치형 게임. 옛 "집부수기" 게임의 손맛을 방치형 성장 구조 위에 얹는다.

| 장르 | 방치형(Idle) + 수동 개입 액션 |

## 3. 코어 루프

```
건물 낙하 (스테이지별 건물 HP / 낙하 속도)
 → 개미 자동 점프 (다리: 점프력 · 점프 이동 속도)
   → 공중 타격 (팔 4슬롯 연타)
     ├─ 착지 전 파괴 성공 → 잔해 드롭 → 일개미가 개미굴로 운반 → 재화
     └─ 파괴 실패 → 건물 착지 → 개미 피격 (다리: 체력)
         ├─ HP > 0 → 다음 건물 계속
         └─ HP = 0 → 이전 스테이지 후퇴 + 자동 진행 OFF
 → 재화로 팔 장비 / 다리 스탯 / 개미굴 강화 → 더 높은 스테이지
```

## 4. 전투 규칙

### 4-1. 자동 + 수동 개입

- 기본 상태에서는 개미가 자동으로 점프하고, 팔 4슬롯 순서대로 타격한다.
- 유저가 탭하면 수동 개입이 발동한다. 자동보다 효율이 높아야 손맛이 산다.
- 수동 개입 = **탭하면 강점프**. 자동 점프보다 높이 뛰어 더 일찍, 더 길게 타격한다. 배율과 쿨타임 수치는 미정.

### 4-2. 실패 · 후퇴 로직

```
ON 건물 착지 (파괴 실패):
  ant.hp -= damage            // 건물 남은 HP에 비례
  IF ant.hp > 0:
    → 다음 건물 낙하
  ELSE (ant.hp == 0):
    → 기절 연출 (납작해짐, 코믹)
    IF stage == 1:
      → 같은 스테이지 재시작 (후퇴 없음)
      → END
    → stage = stage - 1        // 이전 스테이지로 후퇴
    → auto_advance = OFF       // 자동 진행 꺼짐
    → 이전 스테이지 반복 파밍 (방치 수익 유지)
    → [도전] 버튼 노출

ON [도전] 버튼 탭:
  → 실패했던 스테이지 재도전
  IF 클리어:
    → auto_advance = ON        // 클리어 시 자동 진행 복귀
  ELSE:
    → 다시 후퇴, auto_advance = OFF 유지
```

- 자동 진행이 꺼진 상태로 오래 두면, 유저가 막힌 사실을 모르는 채로 같은 스테이지만 반복할 수 있다. **[도전] 버튼 강조 연출**이 필요하다.
- 스테이지 1에서 HP가 0이 되면 후퇴하지 않고 같은 스테이지에서 다시 시작한다.

## 5. 캐릭터 성장

### 5-1. 팔 — 장비 4슬롯

- 팔 4개마다 장비를 하나씩 장착한다. 장착하면 해당 팔의 외형이 바뀐다.
- 장비 수집 요소(가챠/드롭)와 연결되는 핵심 축이다.
- 미니멀 2D라서 장비 4개를 동시에 끼면 실루엣이 뭉개질 수 있다. 무기마다 **고유 실루엣과 색**을 정해두는 규칙이 필요하다.

### 5-2. 다리 — 한 쌍 장비 1슬롯 + 스탯 3종

- 장비: 양쪽 다리에 한 쌍으로 장착한다. 외형은 좌우 대칭으로 바뀐다.
- 스탯은 재화로 레벨업한다.

| 스탯 | 역할 |
|---|---|
| 점프력 | 더 높이 뛰어서, 건물이 높은 위치에 있을 때부터 타격한다. 타격 가능 시간이 늘어난다. |
| 점프 이동 속도 | 위아래 체공 속도. 빨리 올라가고 빨리 내려와서 공격 사이클이 짧아진다. |
| 체력 | 개미 HP. 파괴 실패로 건물이 착지했을 때 버티는 힘이다. |

> 팔은 "공격과 수집", 다리는 "기동과 생존"으로 역할을 나눈다.

## 6. 메인 화면 레이아웃

```
┌─────────────────────┐
│ HUD (재화·스테이지)    │ ~6%
├─────────────────────┤
│   하늘 / 건물 ↓       │
│                     │ 전투 구역 ~84%
│    개미 (점프!)       │
│═════════════════════│ ← 지면
│ 일개미→◉ [강화][장비][굴][상점] │ 땅속 띠 + 메뉴 겹침 10%
└─────────────────────┘
※ 모든 비율은 Safe Area 높이 기준
```

### 땅속 띠 UI 디스크립션

1. **영역 크기**: Safe Area 높이의 10%, 가로 전체 폭. Unity에서는 `Screen.safeArea` 기준으로 앵커를 계산한다.
2. **배경**: 땅속 단면 텍스처. 흙색 단색에 점 패턴 정도로 미니멀하게.
3. **일개미 운반 행렬**: 메뉴 버튼 뒤 레이어에서 좌 → 우로 이동한다. 버튼에 가려도 괜찮은 연출 요소다.
4. **굴 입구**: 띠 우측 끝에 고정. 일개미가 도착하면 운반량 팝업(`+120`)을 띄운다.
5. **메뉴 버튼**: 띠 위에 오버레이로 얹고, 반투명 배경을 깔아 가독성을 확보한다.
6. **개미굴 진입**: 버튼이 아닌 띠 빈 영역을 탭하거나, 띠에서 아래로 스와이프 → 개미굴 전체 화면.
7. **입력 충돌**: 버튼 터치가 우선이다. 스와이프는 시작점이 띠 안일 때만 인정해서, 전투 구역의 수동 탭과 겹치지 않게 한다.

참고: 1080×2340 해상도 기준이면 띠 높이는 약 234px, 일개미 스프라이트는 60~80px 권장. (일반론 수치)

## 7. 개미굴 · 운반 (오프라인 보상)

- 부서진 건물의 잔해가 지면에 떨어지면, 일개미가 올라와 집어서 개미굴로 운반한다. 이 운반이 재화 획득 연출이다.
- 일개미의 수와 레벨이 운반 속도, 즉 오프라인 수익을 결정한다.
- 개미굴 전체 화면에서 방을 확장한다. 굴이 깊어질수록 화면도 아래로 길어져서, **깊이 자체가 성장 지표**가 된다.
- 지면과 띠 사이 연결: 잔해가 지면에 닿으면 0.3초 정도 일개미가 집어가는 연출을 넣어 두 영역을 이어 보이게 한다.
