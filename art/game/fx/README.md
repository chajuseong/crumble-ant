# 건물 파괴 이펙트 후보

| 파일 | 용도 | 기준점 |
| --- | --- | --- |
| `shock_ring.png` | 마지막 타격 지점에서 바깥으로 퍼지는 충격파 | 이미지 중앙 |
| `debris.png` | 주택의 지붕·벽 파편. 방향과 크기를 달리해 사용 | 이미지 중앙 |
| `dust.png` | 파괴 후 주변으로 퍼지는 먼지 | 이미지 중앙 |

PNG는 각각 별도의 정지 이미지이며 애니메이션이나 게임 적용 코드는 포함하지 않는다. `debris.png`는 주택 지붕 조각으로, 다른 건물에 공통 적용하기 전에 색상과 형태를 확인한다.

연출 제안: 일반 타격은 기존 충격 별을 유지하고, 마지막 타격은 충격 별과 링을 강조한 뒤 큰 파편과 먼지가 퍼지게 한다. 재생 시점·지속 시간·수량·화면 흔들림·효과음은 기존 연출과 겹치지 않도록 기개발과 DD가 게임에서 정한다.

원본과 4단계 시안은 `art/production/destruction-vfx-v1/` 및 `art/production/destruction-impact-storyboard-v1.png`에 있다.
