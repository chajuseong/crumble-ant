# 주택 벽 파편 방향 시안

주택 중간층의 크림색 벽과 갈색 창틀·파란 창문을 참고한 `house_wall_source.png`와 폭 256px 비교용 `house_wall_candidate.png`다. 창틀은 원본 그림의 정확한 절취가 아닌 재해석이다. `comparison.png`는 하늘 위에 왼쪽부터 새 벽 파편, 기존 공용 파편, 기존 주택 파편을 각각 128×128px 영역으로 놓는다. 기존 두 파일에는 지붕 형태가 들어 있어 중간층 파괴 때 반복되면 지붕이 미리 나오는 인상을 줄 수 있다.

내장 imagegen에 주택 중간층과 기존 주택 파편을 참고시켜 크림색 벽과 깨진 창문을 가진 독립 파편을 요청했다. `make-preview.cjs`는 sharp로 원본을 잘라 폭 250px로 비율 유지 축소하고 가장자리 3px을 더해 후보·정지 비교를 만든다. 생성물은 그림 정합성 확인용으로, 실제 폰에서의 크기·회전·좌우 반전·배경 대비 및 파편 표현 적합성은 검증하지 않았다.

별도 연출 시안 PR #87에서 '공용 파편'을 일반 층에 사용했지만 공용 그림에도 지붕이 포함돼 있다. 해당 시안의 파편은 실제 벽 파편이 아니다. 이번 파일은 방향 확인용이며 `art/game/`이나 게임 코드를 수정하지 않는다.
