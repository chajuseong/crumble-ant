# 건물 크기 비교 시안

`compare.html`을 브라우저에서 열면 같은 개미와 화면에서 건물 그림을 화면 폭의 50%, 75%, 90%로 비교할 수 있다. 기존 주택과 주택 층 조립 그림을 전환할 수 있다. 저장소의 기존 이미지를 사용하는 정지 목업이다.

`collapse.html`은 화면 폭 75%의 주택을 바닥부터 무너뜨리고 위쪽 조각들이 한 칸 내려앉는 움직임을 보여 주는 독립 시안이다. 첫 타격·층 붕괴·마지막 파괴 버튼으로 장면을 멈춰 볼 수 있고, 다시 보기를 누르면 재생한다. 일반 층에는 공용 파편, 지붕에는 주택 지붕 파편을 사용한다. 기획의 0.12초 낙하를 시안에 적용했지만 실제 게임 실행이나 판정 검증이 아니다. 브라우저 화면 캡처 실패로 장면의 시각 검증은 아직 완료하지 못했다.

50%는 현재 `battle.building.width_ratio = 0.5`와 `building_art.draw_w = 1`을 곱한 그림 폭을 근거로 한다. 다른 HUD·개미 조립·타격 위치는 설명용이므로 실제 게임 화면이나 게임성 검증을 대신하지 않는다. M8 층 건물은 계획 중이며 실제 구현 결과가 아니다.

그림만 키우는 방식은 물리 판정 변경 없이 검토할 수 있으나 HP바·과녁·금·이펙트 위치와 충돌 표시, 폰 화면에서 HUD 가림을 따로 확인해야 한다. `art/game` 및 게임 코드 변경 없음.

개발 검토 참고: 현재 폭 0.5를 유지할 때 그림 배율 `draw_w` 1.5는 화면 폭 75%에 해당한다. 이 경우 기존 체력 바는 판정 폭 기준이고, 금·타격 별·과녁도 기존 좌표를 따르므로 커진 그림에 비해 중앙에 몰릴 수 있다. 시안 수치는 실제 적용 확정이 아니다. 정식 데이터 변경은 생성된 JSON을 직접 수정하지 않고 원본 시트와 데이터 생성 절차를 따른다.
