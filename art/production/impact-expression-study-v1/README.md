# 타격감 · 파편 · 표정 비교 시안

- `destruction-storyboard.png`: 타격 → 한 층 붕괴 → 마지막 파괴의 시각적 강도 비교. 정지 콘셉트이며 별도 이펙트 스프라이트나 인게임 애니메이션은 아니다. 층 파괴는 작게, 마지막은 크게 표현한다.
- `debris-comparison.html`: 현재 게임용 파편과 PR #70의 아파트·공장 후보를 밝은/어두운 배경과 두 크기에서 비교한다. 후보 PNG는 PR #70에서 가져온 비교본이다. AI 재생성으로 창틀과 외곽 등이 달라졌고 화면 회전·실제 폰 검증은 아직 필요하다.
- `ant-expression-concepts.png`: 피격 과장과 기절 표정의 방향 시안이다. 첫 그림도 놀란 표정으로 생성되어 정상 표정이 아니다. 실제 개미 표정 3종의 교체 파일이 아니다. 현재 표정은 머리 크기 조정 후 폰에서 잘 보였다는 검수 기록이 있다(H-25).

모든 파일은 방향 확인용이다. 게임에 연결하지 않았으며 생성된 이미지는 단일 그림으로, 투명 파츠나 규격화된 게임 에셋이 아니다. 표정 납품을 진행할 경우 기존 153×162 동일 캔버스와 머리·더듬이·기준점 일치를 별도로 확인해야 한다. M8 구현 후 실제 파괴 애니메이션과 휴대폰에서 확인한다.

이미지 생성: 내장 imagegen. 프롬프트 요약: 기존 주택과 먼지를 참조해 귀엽고 코믹한 2D 톤의 3단계 파괴 보드, 기존 검은 개미 머리를 참조해 작은 화면에서도 읽히는 과장 피격·기절 표정 보드를 제작.
