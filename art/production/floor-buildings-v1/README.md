# 층 건물 시안 · 주택

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `house_floor_base.png` | 720×230 | 문과 바닥이 있는 1층 |
| `house_floor_mid.png` | 720×230 | 위아래로 반복하는 중간층 |
| `house_floor_roof.png` | 720×362 | 지붕과 굴뚝 |
| `house_floors_preview.png` | 720×1052 | 지붕 + 중간층 2장 + 1층 조립 확인 |

3개 파츠는 모두 투명 RGBA, sRGB, 좌우 투명 여백 7px이다. 픽셀 좌표를 바꾸거나 겹치지 않고 상하로 맞대어 쌓는다. 연결부 8px씩은 동일한 색·폭의 장식 띠라 중간층을 반복해도 경계 픽셀이 같다.

`source/`에는 이미지 생성 원본을 보관한다. 지정된 층 높이에 맞추면서 생성 원본을 변형했고, 특히 1층은 세로가 약 33% 짧아졌다. 최종 아트 확정 전 전체 비율과 이음새를 육안 확인해야 한다. 이 파일은 방향 확인용이며 게임에는 연결하지 않았다.
