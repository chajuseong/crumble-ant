# 건물 파편 정합성 수정 후보

- `apartment.png`: 건물 본체에 없는 금속 난간을 제거한 후보.
- `factory.png`: 공장 본체의 출입문과 비슷하게 줄무늬의 빨간 부분을 짙은 회색으로 바꾼 후보.

방향 확인용 원본이며 `art/game/` 납품본이 아니다. 두 그림은 요청한 부분 외에도 창틀, 균열, 외곽이나 내부 배치가 일부 다시 그려졌다. 기존 게임 파일을 대체하기 전 실제 폰에서 차이가 의미 있는지 확인해야 한다. 게임용으로 채택한다면 폭 256px, 투명 여백, sRGB와 기준점을 다시 검증한다.

`comparison-256/`은 기존 게임 파편과 같은 캔버스로 내보낸 비교용 PNG다. 아파트는 256×251px, 공장은 256×270px이며 각각 RGBA, sRGB, 사방 투명 여백 3px이다. 원본 후보에서 알파 64 초과 영역을 기준으로 자른 뒤 캔버스에 맞추면서, 해당 영역의 가로세로 비율이 각각 약 1.21%, 1.28% 바뀌었다. 게임의 교체 대상은 아니며, 실제 화면에서 위치와 가독성을 확인하기 전의 시험본이다.
