# 받쳐! 터치 과녁 시안

- `target_defend.png`: 위 화살표가 있는 노랑·주황 버튼.
- `target_defend_ring.png`: 버튼 바깥에 겹치는 독립 링. 가운데와 바깥은 투명하다.
- `target_defend_hit.png`: 터치 성공 순간의 번쩍임.
- `target_defend_preview.png`: 게임의 하늘 위에서 왼쪽부터 버튼, 링, 번쩍, 버튼+링을 각각 **180×180px 캔버스**로 배치한 정지 미리보기. 이미지에는 문구를 넣지 않았다.
- `preview-interactive.html`: 180px 과녁을 하늘·주택·어두운 배경에서 보는 별도 시안. 링을 0.7초에 81%까지 줄이고 누르면 번쩍인다. 예시 연출이며 게임의 실제 시간 표시·판정과 다르다.

세 파츠는 512×512 RGBA, sRGB, 가운데 정렬이다. 같은 중심에 버튼을 먼저, 링을 그 위에 겹친다. 버튼이 바깥 링 안에 들어가도록 512px 캔버스 내부의 버튼 그림은 폭 약 406px이므로, 180px 크기로 표시하면 버튼 자체는 약 143px이다. PNG 파일 자체에는 애니메이션과 성공 판정·문구가 없으며 HTML의 링 동작은 예시다. 실제 모바일 화면에서 강점프와의 구분, 다양한 배경이나 과녁 0.7초 동안의 가독성은 게임 적용 후 확인해야 한다.

`source/`는 내장 imagegen 원본(각 1254×1254)이다. 기존 충격 별과 링을 참고해 굵은 진한 갈색 선과 노랑·주황 팔레트, 글자 없는 위 화살표 버튼·빈 링·명중 별을 각각 생성했다. `generate.cjs`는 sharp로 투명 영역의 중심을 맞추고 512px로 리사이즈하며 미리보기를 만든다. 개발용 시안이며 `art/game/`과 게임 코드를 변경하지 않는다.
